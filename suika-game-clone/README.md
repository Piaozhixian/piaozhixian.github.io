# Suika Game Clone (西瓜ゲーム風パズル)

日本で人気の「スイカゲーム（Suika Game）」にインスパイアされた、フルーツ合体パズルゲームのクローンです。
iOS（Swift + SpriteKit）と Android（Kotlin + 自作物理エンジン）の両方をネイティブ言語で実装しています。

商標・キャラクター画像は使用せず、絵文字と独自のカラーリングでフルーツを表現したオリジナル実装です。

## ゲームルール

- コンテナの上から次のフルーツをドラッグして落とします。
- 同じ種類のフルーツ同士がぶつかると合体し、1段階大きい次のフルーツになります。
- 合体するたびにスコアが加算されます（新しい段階の番号 × 10点）。
- 最大サイズの「スイカ」同士が合体すると特大ボーナス（+1000点）で消滅します。
- コンテナ上部の危険ライン（Danger Line）をフルーツが一定時間（1.5秒）超えるとゲームオーバーです。

### フルーツの段階（小 → 大）

| # | フルーツ | 絵文字 |
|---|----------|--------|
| 1 | チェリー | 🍒 |
| 2 | いちご | 🍓 |
| 3 | ぶどう | 🍇 |
| 4 | レモン | 🍋 |
| 5 | オレンジ | 🍊 |
| 6 | りんご | 🍎 |
| 7 | もも | 🍑 |
| 8 | 洋なし | 🍐 |
| 9 | パイナップル | 🍍 |
| 10 | メロン | 🍈 |
| 11 | スイカ | 🍉 |

新しく落とせるフルーツは 1〜5 段階（チェリー〜オレンジ）からランダムに選ばれます。

## ディレクトリ構成

```
suika-game-clone/
├── ios/                 # Swift + SpriteKit (Xcode project)
│   └── SuikaGameClone/
└── android/             # Kotlin + Gradle project
    └── app/
```

## iOS の実行方法

1. `ios/SuikaGameClone.xcodeproj` を Xcode（15以降推奨）で開く
2. iOS 16+ のシミュレータまたは実機を選択してビルド・実行

物理演算は SpriteKit 標準の `SKPhysicsBody`（円形コリジョン）を使用し、
`SKPhysicsContactDelegate` で同種フルーツの接触を検知して合体させています。

## Android の実行方法

1. `android/` を Android Studio で開く（Gradle Sync を実行）
2. minSdk 26 以上の実機・エミュレータで実行

Android 標準SDKには2D物理エンジンが含まれていないため、外部ライブラリに依存せず
`PhysicsEngine.kt` に重力・円形衝突判定・壁との反発を自作しています。
（本サンドボックス環境には Android SDK がなく実機ビルド確認はできていないため、
標準的な Gradle Kotlin DSL 構成で記述していますが、初回 Sync で軽微な調整が必要になる可能性があります）

## 実装のポイント（共通仕様）

- コンテナ幅・高さ、フルーツ半径、合体スコアなどのゲームバランス定数は
  iOS/Android それぞれの `Fruit` 定義内に定数として持たせ、挙動を揃えています。
- 落下前のフルーツは横方向にのみドラッグで移動でき、指を離すと落下を開始します。
- 連続投下を防ぐため、投下後は短いクールダウン（0.5秒）を設けています。
